Открытые лицензии и источники данных

Nivel использует открытые библиотеки и данные. Их авторы и условия перечислены здесь; названия и товарные знаки принадлежат их владельцам.

Данные карты

  • © участники OpenStreetMap; данные доступны по лицензии ODbL — openstreetmap.org/copyright. Правила использования тайлов: operations.osmfoundation.org/policies/tiles.
  • OpenTopoMap — стиль © OpenTopoMap (CC-BY-SA), высоты SRTM; данные © участники OpenStreetMap — opentopomap.org/about.
  • MapTiler, Thunderforest, Stadia Maps, CARTO — подложки по вашему личному ключу, на условиях поставщиков: MapTiler, Thunderforest, Stadia Maps, CARTO. Подпись источника показывается на карте.

Тайлы OpenStreetMap нельзя скачивать заранее для офлайна — это запрещено правилами сервера, поэтому для него офлайн-загрузка в приложении отключена.

Библиотеки приложения для Android (Apache 2.0)

  • osmdroid — отображение карты
  • AndroidX: Jetpack Compose, Material 3 и значки Material, Room, CameraX, Activity, Lifecycle, Core, DocumentFile
  • Coil — загрузка изображений
  • Kotlin и kotlinx — язык и стандартная библиотека

Справочник приборов

Названия производителей и моделей приборов в справочнике используются только для идентификации оборудования. Они принадлежат их владельцам; Nivel не связан с производителями и не одобрен ими. Характеристики в справочнике — справочные, сверяйте их с паспортом прибора.
